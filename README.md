## 🍬 Candy Craft: Ember Realm

A 3D voxel match-3 adventure that mixes candy swapping, a fire companion, and blocky boss battles. Everything — textures, characters, terrain, and sound — is generated procedurally at runtime with Three.js.

### Run it

```bash
npm install
npm run dev      # http://localhost:3002
npm run build    # production bundle in dist/
npm run preview  # serve the production build
```

### How to play

- Tap or click two neighbouring candies to swap them. Only matches of 3+ resolve.
- Match 4+ to forge **TNT**, 5+ to forge an **Ember Core**. Matching a special detonates the area around it, and the hotbar tracks what is on the board.
- Ruby matches (plus TNT and cores) charge Emberpup's fire meter. At 100%, use **Fire Blast** and tap a boss tile to call down a meteor.
- The boss attacks every 4 moves. Break the stone boulders that block the board before they box you in.
- Clear a boss to advance to the next realm.

Works with mouse, touch, and keyboard (`F` aims Fire Blast, `Esc` cancels).
